# Multimodal processing

Image understanding — the project's mandatory non-textual modality.

- Object detection, scene analysis, visual description
- Multimodal embeddings: images + text, cross-modal retrieval, context enrichment
- Output feeds both the Visual agent and the RAG context (visual context alongside retrieved text)

`images/` holds local image assets used or generated by the pipeline (gitignored except for `.gitkeep`).
