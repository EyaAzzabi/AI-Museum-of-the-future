# Prompt library

Versioned prompt library — one file per prompt. For each prompt, document:

- its role in the system (which agent/step uses it)
- the technique used (few-shot, chain-of-thought, structured output, role prompting, guardrails, ...)
- failure cases observed and how they were fixed
- at least one before/after iteration

This is graded separately from the technical report (20% of the final grade) and must also be delivered as a standalone file.

The standalone deliverable is [`PROMPT_LIBRARY.md`](PROMPT_LIBRARY.md): role, techniques, observed failures, fixes and measured before/after for every prompt.
